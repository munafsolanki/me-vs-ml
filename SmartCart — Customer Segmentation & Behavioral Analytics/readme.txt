# SmartCart 🛒

Customer segmentation project using machine learning.

This project uses customer data like **income, age, spending and household information** to find different groups of customers.

### What I used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

### ML stuff

* Data cleaning
* Feature engineering
* StandardScaler
* PCA
* K-Means
* Agglomerative Clustering
* Elbow Method
* Silhouette Score

Basically:

`Dataset → Cleaning → Feature Engineering → Scaling → PCA → Clustering → Customer Segments`

Made this to practice **unsupervised learning and customer segmentation**.
